Read

Datum keeps only the parts of each page that mention your properties, so long papers stay quick.

Extract

Claude, Cerebras, Groq or Gemini, whichever answers first, returns every value with its exact quote and page.

Check

Plain code confirms the quote is on the page, the value is in the quote, the unit fits, and the right material owns the row.
